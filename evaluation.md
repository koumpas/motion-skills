# Practical trials

These trials are ready to run. No output-quality trial occurred during bundle preparation.
Use the same model and available asset set when comparing versions.
Record differences in time, budget, or tools that could affect the comparison.

## 1. A complete launch film

```text
Use motion-launch-film to create a silent 10-second launch film for fal Agent.
Use brand material from https://fal.ai/agent and the actual assets I attach.
Show one real product action and its visible result.
Use editable text and geometry for all precise motion.
If you cannot verify the product action, identify that limit before representing it as real.
Keep the source project for a later revision.
Deliver the MP4 and a concise note with the checks you actually completed.
```

Attach a verified product screen sequence or result before running the trial.
Judge whether the concept uses those assets and makes the product change clear.
Inspect the main transition and the final output at delivery size.
Record whether the source can support another edit.

## 2. A narrow revision

```text
Use motion-choreography on the previous source project.
Change the CTA to "Start with one idea."
Preserve the footage, palette, other copy, shot order, camera movement, and transition timing.
If the new copy requires a layout change, make the smallest necessary change and explain it.
Deliver the revised MP4 and identify the affected time interval.
```

Compare the changed interval and the frames before and after it.
Check the protected properties against the original source and render.
Record every unexpected change. A verbal claim of preservation is insufficient.

## 3. An honest critique

```text
Use motion-review to critique the attached draft against its brief.
Inspect the actual render and use the source if available.
Give timestamped findings with the observed defect, its consequence, and a suggested repair.
Distinguish objective failures from style preferences.
Do not edit the project in this pass.
State which video, playback, and audio checks you could not complete.
```

Check whether each finding matches an observed frame or playback event.
Check that the skill does not invent defects or claim an audio assessment from still images.
Check that critique alone does not modify the project.
